🏀 籃球隊 LINE 機器人使用與管理手冊

群組互動、活動報名、後台管理及候補補助邏輯全解析

📱 第一篇：球友群組日常操作指南

1. 怎麼叫出 7 天內的活動清單？

  • 一鍵呼叫：只要在群組內隨便說話，或直接標記機器人（@機器人），機器人就會自動跳出未來 7 天內所有活動的左右滑動輪播卡片。
  • 內容包含：同時包含「本群季租活動」與「主辦人同步開放給本群的跨群組臨打活動」，讓你一眼掌握本週所有球局！

2. 季租固定班底：請假與銷假

  • 我要請假：找到該場次的季租卡片，點擊下方的 [ 請假 ] 按鈕。系統會立即將你的名額釋出給候補區的球友。
  • 臨時能去（銷假）：如果請假後突然可以去了，點擊 [ 銷假 ]。系統會把名額要回來；若原本的空位已經被候補遞補，系統會自動將最後一位遞補上正選的球友退回候補等待區（⏳），確保公平。
  • 管控期限制：若球隊目前處於「管控期」，非固定班底不能請假（只能候補），固定班底請假才會釋出名額。

3. 候補區操作（+1 ~ +4）

  • 如何排候補：季租或跨群組臨打卡片下方皆有一整排快速按鈕 [+1] 至 [+4]。點擊後即可即時排隊。
  • 自動通知：當前面有人請假、輪到你遞補上正選（✅）時，機器人會自動在聊天室標記 @你的名字 發送祝賀通知！
  • 取消候補：若不小心多按或行程有變，點擊 [-1] 至 [-4] 即可扣除或取消對應人數。

4. 跨群組臨打報名

  • 自動顯示：只要管理員將某場跨群組臨打開放給本群，當你在群組標記機器人時，該場臨打卡片就會自動出現在滑動選單中。
  • 直接操作：不用打繁瑣指令，直接在卡片下方點擊報名與取消按鈕即可。

5. 自動身分綁定

  • 機器人具備自動學習功能，只要你在群組發言或點擊按鈕，就會自動被記錄。若主辦人已在後台為你設定好姓名與座號（例如 `#01 小明`），系統會自動完成身分綁定。

⚖️ 第二篇：核心邏輯解析（請假順序與候補補助）

Q：請假的先後順序，會不會影響「候補成功的補助次數」計算？

答案是：會！而且系統完全依循「嚴格的時間先後順序（FIFO，先進先出）」來確保絕對公平。

  • 請假的釋出順序：當多位固定班底請假時，系統會按照請假完成的時間先後順序來排列釋出的空位。也就是說，「越早請假的人，其釋出的名額就越優先用來讓候補區的第一順位遞補」。
  • 候補的遞補順序：同理，候補區也是按照登記的先後順序排隊。
  • 「候補成功補助次數」怎麼算？
    • 在後台的季租統計報表中，每一位請假的固定班底都會被追蹤其「補助次數（Subsidy Count）」。
    • 當固定班底 A 請假，剛好讓候補區的 B 遞補成功時，這場活動的「遞補名額」就會算在 A 的頭上，計為一次補助。
    • 這代表：雖然你請假沒打到球，但因為你「提早請假、釋出空位」，成功讓其他想打球的人（候補）補上位，系統把這視為你對球隊流動的貢獻（補助次數）。這項數據在季租結算時非常實用！

🛠️ 第三篇：主辦人與管理員私訊後台

所有管理與數據統計，請透過與機器人的私人對話框（DM）輸入 管理 進入。

1. 成員與權限管理

  • 身分與座號：檢視固定班底與非班底（30人分頁），可為成員設定專屬編號（如 `#01` 至 `#20`），卡片與名單會自動按座號整齊排列。
  • 後台授權：可將信任的球友升格為 群組管理員、查看統計 或 臨打後台管理。
  • 模式切換：一鍵切換 收集期（所有人可請假）與 管控期（僅固定班底可請假）。

2. 季租活動排程管理

  • 單場與批次新增：支援單場建立，或一鍵「批次新增未來 26 週」活動，自動推算每週時間、球場地點與候補開放日。
  • 手動調度名單：主辦人可隨時進入後台，強制將某位成員設為請假/出席，或手動增減候補名單，不受排隊限制。

3. 出席率與候補財務統計報表

  • 多維度查詢：支援「按季（1-3月等）」、「按半年」、「全年」或「自訂日期區間」查詢。
  • 數據一目了然：顯示期間內已舉辦總場次、總候補成功人次。
  • 個人明細：列出每位固定班底的出席次數、請假次數、候補補助次數、精準出席率（達 80% 自動顯示綠字），是球隊計算季費、場地費分攤的最佳神兵利器！

4. 跨群組臨打活動統籌

  • 建立跨群組臨打局後，可自由勾選要開放同步到哪幾個 LINE 群組中顯示。
  • 可隨時手動新增外援報名（如「阿明 +2」），或手動調整正選與候補名單。
